Hired to build a high-performance WebRTC desktop GUI in Rust; when the tooling proved immature, the R&D
pivoted into something better — designing and developing the first MVP of a **distributed WebRTC media
server in Rust**, architected for scalability and real-time efficiency. Owned the whole DevOps story
end to end: CI/CD pipelines and Pulumi infrastructure-as-code.

Real-time media, no central broker rent — the same peer-to-peer instinct that later showed up in nibli's
federation layer.
